# عزل

موقع يعزل الموسيقى بالذكاء الاصطناعي، مجاني بالكامل ويشتغل على جهازك:

1. **إزالة الموسيقى:** يبقى الكلام بس، وإذا كان الملف فيديو يرجع لك الفيديو نفسه بدون موسيقى.
2. **فصل أغنية:** يطلع لك الصوت لحاله والموسيقى لحالها.

تقدر ترفع ملف من جهازك، أو تحط رابط من يوتيوب وتيك توك وإنستقرام وغيرها.

## التشغيل

```bash
pip install -r requirements.txt
uvicorn app:app
```
بعدها افتح http://localhost:8000

- أول مرة يحمّل نموذج الذكاء الاصطناعي (حوالي 80 ميقا)، وبعدها يشتغل على طول.
- إذا ffmpeg مو مثبت في جهازك، الموقع يستخدم النسخة الجاهزة من imageio-ffmpeg.
- إذا وقفت روابط يوتيوب، حدّث yt-dlp: `pip install -U yt-dlp`
- إذا عندك كرت شاشة NVIDIA، الموقع يستخدمه تلقائيًا ويصير أسرع بكثير.

## الإعدادات (اختياري)

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `MODEL` | `htdemucs` | `htdemucs_ft` جودته أعلى بس أبطأ 4 مرات تقريبًا |
| `MAX_MINUTES` | 20 | أطول مدة للمقطع |
| `MAX_UPLOAD_MB` | 500 | أكبر حجم للملف |
| `JOBS_PER_HOUR` | 20 | حد الطلبات لكل جهاز بالساعة |
| `JOB_TTL_MIN` | 60 | بعد كم دقيقة تنحذف الملفات |
